# ScreenTranslator

Офлайн-переводчик экрана для Android 11+: плавающая кнопка поверх игры → снимок экрана →
распознавание текста → перевод на русский прямо на телефоне → плашки поверх оригинала.
Для визуальных новелл есть выбор области (окно диалога) и авто-режим.

## 1. Собрать APK через GitHub

Ничего ставить не нужно, сборка идёт на серверах GitHub бесплатно.

1. Зарегистрируйтесь на [github.com](https://github.com).
2. **New repository** → имя `ScreenTranslator` → **Private** → **Create repository**.
3. Нажмите **uploading an existing file** и перетащите **содержимое** распакованной папки
   (всё, что внутри `ScreenTranslator`, а не саму папку) → **Commit changes**.
4. Папка `.github` скрытая и при перетаскивании часто теряется. Проверьте, что она есть в репозитории.
   Если нет: **Add file → Create new file**, имя `.github/workflows/build.yml`,
   вставьте содержимое этого файла из архива → **Commit changes**.
5. Вкладка **Actions** — сборка запустится сама, идёт 5–10 минут. Зелёная галочка — готово.
6. На телефоне откройте `github.com/<ваш логин>/ScreenTranslator/releases/latest`
   и скачайте `ScreenTranslator.apk` (нужно войти в GitHub в браузере).

Каждое следующее изменение в репозитории пересобирает APK автоматически.
Ключ подписи постоянный (`keystore/`), поэтому новые версии ставятся поверх старой.

## 2. Установить и настроить

1. Откройте APK → разрешите установку из браузера/файлового менеджера.
   Если Play Protect предупредит — «Всё равно установить».
2. Откройте ScreenTranslator → в разделе «Языки» скачайте **Английский** и **Русский**.
3. «Открыть Спец. возможности» → ScreenTranslator → включить.
   Если переключатель серый («Ограниченная настройка», Android 13+) — инструкция прямо в приложении:
   «О приложении» → ⋮ → «Разрешить ограниченные настройки».
4. «Отключить оптимизацию батареи». На Xiaomi ещё «Контроль активности → Нет ограничений» и «Автозапуск».

## 3. Пользоваться

- **Тап** по кнопке — перевести экран. Ещё тап или касание игры — убрать перевод.
- **Долгий тап** — меню: язык оригинала, область, авто-режим, настройки.
- **Новелла:** меню → «Выбрать область» → обведите окно диалога → «Готово» →
  меню → «Авто-режим: включить». Перевод появляется над окном диалога сам, когда меняется реплика.
  Тап по кнопке в авто-режиме — перевести прямо сейчас.
- Имена персонажей впишите в **Словарь** — так они не будут переводиться как обычные слова.

## 4. Проверка по этапам

| Этап | Что сделать | Ожидается |
|---|---|---|
| 1. Скелет | Включить сервис, открыть игру | Кнопка видна и перетаскивается |
| 2. OCR | Настройки → «Режим проверки» → тап по кнопке | Зелёные рамки точно на тексте |
| 3. Перевод | Выключить режим проверки, включить режим полёта, тап | Русские плашки на месте текста |
| 4. Новелла | Область + авто-режим | Перевод сам меняется вместе с репликой |

Если что-то пошло не так — пришлите в чат строку с ошибкой из лога сборки
(Actions → красный шаг) или опишите, что видно на экране.

## Устройство кода

`app/src/main/java/com/personal/screentranslator/`

| Файл | Что делает |
|---|---|
| `TranslatorAccessibilityService.kt` | Сервис: кнопка, меню, оверлей, ручной перевод, авто-режим |
| `ScreenCapturer.kt` | Снимок экрана через спец. возможности, лимит частоты |
| `OcrEngine.kt` | ML Kit Text Recognition (латиница, японский, китайский, корейский) |
| `TextMerger.kt` | Склейка строк в абзацы, имя говорящего отдельно |
| `TextTools.kt` | Фильтр мусора, исправление КАПСА |
| `UserDictionary.kt` | «Не переводить», свой перевод терминов, исправления |
| `TranslationCache.kt` | LRU-кеш переводов с сохранением на диск |
| `MlKitTranslator.kt` | Перевод ML Kit и языковые пакеты (интерфейс `Translator`) |
| `TranslationPipeline.kt` | OCR → склейка → фильтр → кеш/перевод → словарь |
| `OverlayRenderer.kt` | Плашки с подбором шрифта, панель авто-режима, рамки проверки |
| `FloatingButton.kt`, `FloatingMenu.kt` | Кнопка и меню |
| `RegionSelector.kt` | Выбор области пальцем |
| `AutoWatcher.kt` | Авто-режим: следит за областью, ждёт, пока реплика допечатается |
| `SettingsScreen.kt`, `MainActivity.kt` | Экран настроек на Compose |

Распознавание и перевод — Google ML Kit, перевод выполняется на устройстве.
